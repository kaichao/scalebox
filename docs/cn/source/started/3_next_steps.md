# 3. 后续学习路径

根据您的使用场景，选择以下学习路径：

## 3.1 如果你是最终用户（运行应用）

### 学习重点
- Scalebox核心概念（App、Module、Task、Slot）
- 如何运行和管理应用
- 集群操作和监控

### 推荐学习路径
1. 阅读 **用户指南** 的 "核心概念" 章节
2. 学习 **用户指南** 的 "运行应用" 章节
3. 探索 **用户指南** 的 "应用示例" 章节

## 3.2 如果你是应用开发者（开发应用）

### 学习重点
- 应用设计模式和最佳实践
- 模块开发技术
- 高级特性使用

### 推荐学习路径
1. 阅读 **开发指南** 的 "编程模型" 章节
2. 学习 **开发指南** 的 "应用设计" 章节
3. 掌握 **开发指南** 的 "模块开发" 章节

## 3.3 如果你是系统管理员（管理集群）

### 学习重点
- 多节点集群部署
- 集群配置和管理
- 性能优化和故障排查

### 推荐学习路径
1. 阅读 **用户指南** 的 "安装部署" 章节
2. 学习 **开发指南** 的 "集群管理" 章节
3. 了解 **附录** 的 "最佳实践" 章节

# 不变式条目模板

复制以下格式到 `10-invariants.md` 或对应 feature 的 README。

````markdown
### INV-<编号> <一句话规则>

- **现象**：在什么场景下遇到（触发条件）。
- **规则**：必须遵守什么 / 绝对不能做什么。
- **为什么**：机制层面的原因（一句话说清）。
- **反例/后果**：违反时的具体表现（错误码、卡死、静默错误等）。
- **源码指针**：`go-scalebox/<path>`（符号）。
- **置信度**：已交叉验证（≥2 个应用）/ 单项目来源。
- **适用范围**：平台通用 / 仅某模式（如 HOST-BOUND）/ 仅某阶段（建 app、领任务、退出）。
````

## 填写要求

- 一条一个规则，不合并；有条件的规则分别写。
- 规则用祈使句；禁止项写"不要…"。
- 反例要可观察：错误码、状态码、日志关键字、卡死现象。
- 交叉验证的证据写来源（应用 / 设计文档 / 源码）。
- 同一主题的条目集中在同一小节，编号全局唯一。

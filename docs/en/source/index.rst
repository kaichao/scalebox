Welcome to the Scalebox Documentation Library!
==============================================

Choose a learning path based on your use case:

- **End users (running apps)**: start with "Getting Started" → then read "Core Concepts", "Running Apps", and "Example Apps" in the User Guide
- **App developers (developing apps)**: start with "Programming Model" in the Developer Guide → "App Design" → "Module Development"
- **System administrators (managing clusters)**: start with "Installation" in the User Guide → "Cluster Management" → "Operations"
